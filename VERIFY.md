* [ ] Doctor name & specialty for each visit log.

* [ ] Individual "Download Report / Advice PDF" button per record.


* [ ] **Tab 2: Diagnostic / Test Reports List**
* [ ] Test title/category (e.g., CBC Blood Test, Chest X-Ray, ECG, USG).

* [ ] Individual "Download Report PDF / Image" button per test item.
